# Earth surface imagery

`earth-blue-marble.png` is the 2048 × 1024 Blue Marble mosaic from
[NASA SVS](https://svs.gsfc.nasa.gov/2915/).

Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio.
Blue Marble data courtesy of Reto Stockli (NASA/GSFC) and NASA's Earth Observatory.

Source: https://svs.gsfc.nasa.gov/vis/a000000/a002900/a002915/bluemarble-2048.png

Bundled locally, unmodified. This is a static geographic visualization, not live weather
or a simulation of current sunlight. No NASA endorsement is implied.
